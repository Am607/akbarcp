# akbarcp.com

Personal portfolio of Akbar CP — Full Stack & Flutter Developer, Kochi.

Built with Next.js (App Router), Tailwind CSS v4 and lucide icons. Light and dark themes
(follows the system, with a toggle that remembers your choice).

## Develop

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

## Editing content

All text lives in `src/data/site.ts`: profile, socials, projects, experience, skills and process steps.
